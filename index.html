Live Sweep: HC-SR04 Sensor & Processing IDE Radar GUI 🔍 Zoom Photo

How It Operates

SG90 servo motor sweeps sensor continuously from 0° to 180°. HC-SR04 transmits ultrasonic acoustic pulses; when reflected by obstacles, echo duration is computed into distances and sent via 9600-baud UART serial to Processing IDE.

Distance Formula: Distance (cm) = (Echo Duration × 0.034) / 2
0°–180° Servo Sweep
2–400 cm Object Range
9600 Baud UART Serial
15° Beam Angle
Cyan: Active Sweep Beam Red: Obstacle Detected Green: Clear Radius Arc
